# INT332: DevOps Virtualization and Configuration Management

Welcome to the repository for **INT332**. This space contains coursework, lab assignments, infrastructure scripts, and notes covering the core principles of DevOps, with a specific focus on virtualization techniques and configuration management automation.

## 📚 Course Overview
This course explores the intersection of software development and IT operations. Key areas of practical application include:
* **Virtualization & Containerization:** Creating, deploying, and managing virtual environments and containers.
* **Configuration Management:** Automating the provisioning, configuration, and management of infrastructure as code (IaC).
* **Automation:** Streamlining deployment pipelines and system administration tasks.
